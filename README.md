# DroidLoom

DroidLoom is an Android Agent runtime and workflow compiler project.

The project documentation that was previously pushed directly to `main` is being quarantined because it has not received human review yet. Reviewed documentation should enter `main` only through PR approval.

Current branch policy:

- `dev`: integration branch for emulator-based development and documentation review.
- `main`: protected branch for reviewed material only.
- Docs must be reviewed by a human before merging to `main`.

Open documentation review PRs should use `dev -> main` or a dedicated `docs/* -> main` branch after the cleanup PR lands.
